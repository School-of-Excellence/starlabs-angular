## 1. Architecture summary

- **Stack:** Angular 19 (standalone components, SSR via @angular/ssr) + Firebase (Auth, Firestore, Storage, Functions, FCM). PWA (service worker).
- **Bootstrap:** `src/main.ts` → `AppComponent` + `app.config.ts` (providers: Firebase, Firestore, Storage, Auth, HttpClient, Material, animations, SW).
- **Routing:** `src/app/app.routes.ts` — 212 active routed screens, lazy-loaded (`loadComponent`), nearly all behind `authGuard`.
- **Auth & roles:** Firebase Auth (email/password) → `profile_data.role_ref` → **`users_roles`** (boolean role flags) → route ACL via the `dashboard` collection. (Corrected 2026-06-02 from live data: `role_ref` targets `users_roles`, not `eisroles`; `eisroles` is the separate *specialist-role* catalog used in scheduling — see `specs/AUTH-ROLES.md`.) No Firebase custom claims. Roles seen: admin, developer, ah, ahmember, eis, capacityplanner, participant.
- **Central hub:** `AuthguardService` (~1,800 lines, 60+ methods) — auth, Firestore access maps, roles, FCM, IndexedDB cache. Highest-connectivity node in the knowledge graph.
- **Commercial model:** 48 journeys / 104 products across **5 delivery modes** — Priority (1:1 appointments), Event, Installation Event (live workshops), Big (cohort/marathon), Investment. Journey lifecycle state in `participantjourneyproduct`.
- **Conferencing:** LiveKit (primary, "OpenVidu" components), Zoom Meeting SDK (legacy/big events), Amazon Chime Voice Focus (fallback), Picovoice Koala (noise suppression), RecordRTC.
- **Known architectural debt:** heavy component duplication (Clone/Clone-2/Duplicate/old variants — 7 of top-10 graph hubs); see `TECHNICALDEBTS.md`.

## 5. Firebase Cloud Functions

Base URL: `https://us-central1-{firebase.projectId}.cloudfunctions.net/`. Called via HttpClient.
- Conferencing (LiveKit): `createOpenViduToken`, `openViduCloseRoom`, `openViduStartRecording`, `openViduStopRecording`, `kickParticipant`, `muteParticipant`, `flushOpenviduCallQuality`
- Scheduling: `profileAvailability` (generate specialist slots)
- Infra (AWS): `startMasterNodeHTTP`, `stopMasterNodeHTTP`, `scaleMediaNodes`
- Messaging: FCM send (server key currently hardcoded client-side — see TECHNICALDEBTS).

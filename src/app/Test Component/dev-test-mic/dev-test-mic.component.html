How it works
1 Mode 1 — File: Upload any audio. RAW + DF3 (offline) + Koala (real-time) outputs produced. All three hearable and downloadable.
2 Mode 2 — Live: All three channels run simultaneously in real time. Toggle each channel's speaker on/off independently. Level meters show noise reduction live.
3 Mode 3 — Recording: Records all three simultaneously as lossless WAV. After stopping, run PESQ/STOI quality analysis via the local Python server.
4 PESQ/STOI: Start python quality_server.py in a terminal. Click "Run Analysis" — scores appear in ~2 seconds. RAW is the reference signal.

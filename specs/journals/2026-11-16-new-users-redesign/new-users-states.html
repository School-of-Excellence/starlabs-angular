01

Loading

No blank page and no lone spinner. The frame paints at once, rows hold their shape, and the count may arrive after the rows.

02

Empty and error states

One calm pattern: a ringed icon, a Playfair line, one sentence, and the single next step.

03

Filters and search

Pills stay short (name plus a count); the readout under the toolbar is the single place that spells out values. Changes apply live and each panel's footer counts the matches.

04

Columns and file tools

Columns sits at the end of the toolbar; Select from file and Manage tags sit in the page header because they act on the whole list.

05

Tag dialogs

One dialog family: Manage tags (page header), Assign tags (a row's tag button), Edit tags (the selection dock). A thin gold ring marks a change not yet saved.

06

Table behaviour

Columns that come and go with filters, sorting, paging, the pinned header and the details inside a row.

07

Selection

The navy dock rises when the first person is ticked and stays pinned above the bottom edge while rows scroll; its panels open upward. Scope is always stated: this page, or everyone who matches.

08

Below 900px

These phones run the real screen markup: the rules key off the content width, so the same table becomes dense cards. The tablet layout is new-users-ui.html opened at 820px.
